## 💻 Instrucciones de Uso

1. **Uso Local**: Haga doble clic en el archivo `index.html` para abrirlo en su navegador preferido (Google Chrome, Mozilla Firefox, Microsoft Edge o Safari).
2. **Subida a GitHub Pages**:
   - Suba los archivos `index.html`, `style.css` y `app.js` a su repositorio.
   - Active GitHub Pages en la rama principal.
   - Tendrá el sistema disponible en la web sin servidores backend.
3. **Archivos incluidos**:
   - `index.html`: Estructura semántica con barra de navegación, métricas y tabla de indicadores.
   - `style.css`: Estilos visuales institucionales SENA (paleta Verde `#0D631B` y Azul `#005A8C`).
   - `app.js`: Base de datos en memoria, sistema de roles y filtros dinámicos.
